# Probability of an event
$$
\huge P(event) = \frac{\text{number of ways event can happen}}{\text{total number of possible outcomes}}
$$
## Example
* a coin flip
$$
\huge
P(heads) = \frac{\text{1 way to get heads}}{\text{2 possible outcomes}} = \frac{1}{2} = \text{50\%}
$$
