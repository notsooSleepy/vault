# Binomial distribution
* needs to be sequence of *independent* events
* probability distribution of the number of successes in sequence of independent events
* for example, the number of heads in a sequence of coin flips
* described by *n* and *p*:
	* n: total number of events
	* p: probability of success
![[Pasted image 20251126204443.png|600]]
## Expected value
* *n x p* 
expected number of heads out of 10 flips = 10 x 0.5 = 5
if we don't know p, but know n and the expected value:
$$
\huge p = \frac{\text{expected value}}{n}
$$
