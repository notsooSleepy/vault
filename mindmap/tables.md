# tables
1. Table naming
	* clear
	* refer to data
	* lowercase
	* use underscores not spaces
2. Records and fields
	* rows = records
	* columns = fields
	* each record contains data for individual observation
	* fields contain one piece of information from all records
3. Field names
	* lowercase
	* use underscores
	* singular not plural
	* unique to table and other fields
4. Unique identifier = key
5. Using multiple tables is less prone to data duplication
