# Data life cycle
1. Planning and collecting
	* planning for other stages of the data life cycle
	* share of roles and responsibilities
	* to achieve optimal results in terms of time and cost
	* collect or create data
2. Storing and managing
	* data stored in database or data warehouse
	* easily accessible to the right person
	* removal of PII
3. Cleaning and processing
	* formatting data
	* missing data
	* transforming data
4. Analyzing and visualizing
	* analyzing raw data for new insights
	* data is easier to interpret when visualized
	* analyzing and visualizing data is done in various ways
5. Sharing
	* communicate your results
	* dashboards, reports, papers
6. Archiving/destroying
	* decide if data should be kept or deleted
	* data archiving:
		* data backups
		* documentation
		* digitizing
	* data destruction:
		* in rare cases
		* protecting private information
		* resources can be freed up
